# MeisterHand Handwerksservice

Moderne, responsive Landingpage für einen Handwerksbetrieb, gebaut mit Next.js (App Router), TypeScript, Tailwind CSS und Framer Motion.

## Entwicklung starten

```bash
npm install
npm run dev
```

Die Seite ist danach unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Produktion

```bash
npm run build
npm run start
```

## Inhalte

- Hero-Sektion mit Video-Hintergrund (Desktop/Tablet) und Bild-Fallback (Mobile)
- Leistungen, Über uns, Galerie, Referenzen, Kontaktformular
- Farbige, eingebettete Google Maps Karte im Kontaktbereich
- Alle Fotos/Videos sind lizenzfreies Material (Pexels / Pixabay) und liegen unter `public/images` bzw. `public/videos`
